Pipelines, not agent loops.

Most personal agents let a model decide what to call, when and how often. Horae writes the control flow down, so you can read it, test it and trust it next to your mail, your calendar and your kids' school accounts.

One bounded LLM step

A fixed skill, an output schema, a model alias and a cost ceiling, and no tools. Same input, no call: a run that finds nothing new costs nothing.

Plugins propose, the core applies

Plugins return intents. Horae validates them, shows the dry-run diff, writes the journal, and horae undo restores every note byte for byte. horae replay re-runs a record and compares.

Permissions you can read

Each plugin declares the hosts it calls, the secrets it needs, the paths it touches and the intents it may return. You approve them at install; they are enforced at run time.

A marketplace that is just git

horae plugin add github@0.6.0 clones the plugin, verifies the tag and the commit, and pins it in horae.lock. Nothing updates itself.

Bring your own model

The Anthropic API, your own claude -p, any OpenAI-compatible endpoint, or a local Ollama. Each pipeline names a model alias and a budget; horae usage shows what each one cost.

Every run, written down.

The morning note is one short YAML file. You can see every source, the one model call and its budget, and the only file it may write.

pipelines/daily-brief.yamlpack-daily-brief
name: daily-brief
trigger: { cron: "30 5 * * *" }
steps:
  - collect:
      - calendar.events: { start: "{{ '{{date}}' }}", days: 2 }
      - obsidian.open_tasks: { limit: 100 }
      - github.review_requests: { max_items: 20 }
  - llm:
      skill: daily-brief/rank-and-word
      model: default
      budget: { usd: 0.15, tokens_out: 4000 }
      on_unchanged_input: skip   # same input, no call
  - act:
      - obsidian.write_note:
          path: "Daily/{{ '{{date}}' }}.assistant.md"
          mode: replace-owned
  1. CollectPlugins read your calendar, vault and GitHub over MCP stdio, each inside the hosts and secrets it declared.
  2. Rank and wordOne model call with a fixed skill. Its answer must match the skill's JSON Schema, or the run stops.
  3. Dry-runhorae run daily-brief --dry-run prints the diff. Nothing is written.
  4. Apply and journalThe core writes only the block the plugin owns, and records the run with its inputs and cost.
  5. Undo, replayhorae undo <run> restores the note. horae replay <run> re-executes it from the record.

Write your own plugin

The Horae guard the gates.

Approved at install

Hosts, secrets, paths and intents are shown before anything is pinned. An upgrade that asks for more asks you again.

Enforced at run time

Third-party plugins run only in a container: non-root, read-only, no capabilities, and no network you did not allow.

Untrusted content stays data

Mail and web text reach the model as data, never as instructions, and the model has no tools to act on them.
